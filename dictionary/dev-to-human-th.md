# พจนานุกรมคำศัพท์เทคนิคสู่ภาษาไทยสำหรับผู้ใช้งานทั่วไป (Developer to Human Plain Thai Dictionary)

เอกสารฉบับนี้รวบรวมคำศัพท์ทางเทคนิค ระบบหลังบ้าน (Backend), ฐานข้อมูล (Database), โครงสร้างพื้นฐาน (Infrastructure), และคำศัพท์ไอทีที่มักรั่วไหลขึ้นมาบนหน้าจอผู้ใช้ (User Interface) พร้อมคำแปลและสำนวนภาษาไทยที่ผ่านการทดสอบว่า **เข้าใจง่าย สุภาพ และไม่สร้างความสับสนหรือตื่นตระหนก**

---

## 1. หมวดความปลอดภัยและการยืนยันตัวตน (Authentication & Security)

| ศัพท์เดิม / ศัพท์เทคนิค | ปัญหาที่พบ | คำแนะนำสำหรับผู้ใช้งานทั่วไป | ตัวอย่างบริบทการใช้งาน |
|---|---|---|---|
| `Credentials invalid` | ผู้ใช้ไม่เข้าใจว่าคืออะไร | **ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง** | หน้าจอลงชื่อเข้าใช้งาน |
| `Session Expired` / `Token หมดอายุ` | ศัพท์เทคนิคของเว็บ | **หมดเวลาการเชื่อมต่อเพื่อความปลอดภัย — กรุณาเข้าสู่ระบบใหม่อีกครั้ง** | แจ้งเตือนเมื่อออกจากระบบอัตโนมัติ |
| `Access Denied (403)` | ไม่บอกทางออก ขู่ผู้ใช้ | **คุณไม่มีสิทธิ์เข้าถึงข้อมูลในส่วนนี้ — หากต้องการใช้งาน กรุณาติดต่อหัวหน้างานหรือผู้ดูแลระบบ** | หน้าจอที่ถูกจำกัดสิทธิ์ |
| `CSRF Token mismatch` | ศัพท์เทคนิคการป้องกันเว็บ | **หน้าเว็บหมดอายุ กรุณารีเฟรช (โหลดหน้าใหม่) แล้วลองอีกครั้ง** | ข้อผิดพลาดตอนส่งแบบฟอร์ม |
| `Hash` / `Salt` / `Encryption` | ศัพท์วิทยาการรหัสลับ | **การเข้ารหัสรักษาความปลอดภัย** | นโยบายความปลอดภัย |
| `OTP / MFA` | คำย่อภาษาอังกฤษ | **รหัสยืนยันตัวตน 6 หลักทาง SMS** | ขั้นตอนยืนยันความปลอดภัย 2 ชั้น |
| `Force Logout` | ภาษาข่มขู่ | **ออกจากระบบในอุปกรณ์อื่นทั้งหมดแล้ว** | การจัดการอุปกรณ์ที่ล็อกอิน |

## 2. หมวดสถานะและการประมวลผลหลังบ้าน (System State & Enums)

| ศัพท์เดิม / Enum State | ปัญหาที่พบ | คำแนะนำสำหรับผู้ใช้งานทั่วไป | ตัวอย่างบริบทการใช้งาน |
|---|---|---|---|
| `DRAFT` | ทับศัพท์ภาษาอังกฤษ | **ฉบับร่าง (ยังไม่ส่ง)** | ป้ายสถานะเอกสาร |
| `PENDING_REVIEW` | ศัพท์โปรแกรมเมอร์ | **รอเจ้าหน้าที่ตรวจสอบ** | ป้ายสถานะเอกสาร |
| `READY_FOR_TARGET_SETTER` | รั่วไหล State Machine ภายใน | **ส่งต่อแล้ว — รอผู้กำหนดเป้าหมายเลือกผู้รับ** | สถานะส่งต่อแคมเปญ รพ. |
| `PENDING_EXECUTIVE_APPROVAL`| ยาวและเป็นภาษาเทคนิค | **รอผู้อำนวยการอนุมัติ** | สถานะการขออนุมัติ |
| `APPROVED` | ทับศัพท์ | **อนุมัติแล้ว** | ป้ายสถานะเอกสาร |
| `REJECTED` | ดูตัดรอน | **ส่งกลับแก้ไข (ระบุเหตุผล)** | สถานะเมื่อไม่อนุมัติ |
| `QUEUED` / `IN_QUEUE` | ผู้ใช้ไม่รู้ว่าระบบทำอะไรอยู่ | **อยู่ในคิวเตรียมส่ง (ลำดับที่ X)** | สถานะการส่งข้อความ/จดหมาย |
| `PROCESSING` / `IN_PROGRESS`| กว้างเกินไป | **กำลังประมวลผล… (ประมาณ X นาที)** | แถบแสดงความคืบหน้า |
| `SUCCESS` / `HTTP 200` | ภาษา HTTP | **บันทึกข้อมูลเรียบร้อยแล้ว** | ข้อความแจ้งเตือน (Toast) |
| `FAILED_RETRY` | ผู้ใช้ตกใจว่าพัง | **ส่งไม่สำเร็จชั่วคราว — ระบบกำลังลองส่งใหม่อัตโนมัติ** | รายการส่งข้อความ |
| `DEPRECATED` | ศัพท์สถาปัตยกรรม | **ยกเลิกการใช้งานแล้ว** | รายการฟังก์ชันเก่า |

## 3. หมวดเครือข่ายและระบบคลาวด์ (Network, Infrastructure & Telemetry)

| ศัพท์เดิม / ศัพท์เทคนิค | ปัญหาที่พบ | คำแนะนำสำหรับผู้ใช้งานทั่วไป | ตัวอย่างบริบทการใช้งาน |
|---|---|---|---|
| `HTTP 500 Internal Server Error` | ผู้ใช้ไม่รู้จะทำอย่างไร | **ระบบขัดข้องชั่วคราว เจ้าหน้าที่กำลังตรวจสอบ กรุณาลองใหม่อีกครั้งใน 5 นาที** | ข้อผิดพลาดของเซิร์ฟเวอร์ |
| `HTTP 504 Gateway Timeout` | ศัพท์เกตเวย์ | **การเชื่อมต่อใช้เวลานานเกินไป กรุณาตรวจสัญญาณอินเทอร์เน็ตแล้วลองใหม่** | ข้อผิดพลาดเครือข่าย |
| `Ping Latency: 45ms` | ตัวชี้วัดวิศวกรรม | **สถานะระบบ: เชื่อมต่อปกติ** | ป้ายสถานะการทำงาน |
| `Min Gap: 0.35s` | พารามิเตอร์ควบคุมอัตรา | *(นำออกจากหน้าจอผู้ใช้ ให้ระบบตั้งค่าที่ปลอดภัยที่สุดให้อัตโนมัติ)* | การตั้งค่าระบบส่งข้อความ |
| `Parallel Workers: 4` | ศัพท์ Concurrency | **ระดับความเร็ว: ความเร็วปกติ (แนะนำ)** | ตัวเลือกการส่งงาน |
| `Throughput: 120 req/s` | ตัวชี้วัดระบบ | **ความเร็ว: ประมาณ 120 รายการต่อนาที** | หน้าจอสถิติ |
| `Server: coophpr.thaiddns.com` | ความเสี่ยงความปลอดภัย (Recon) | *(นำออกจากหน้าจอผู้ใช้)* | หน้าล็อกอิน / ส่วนท้ายเว็บ |
| `Deploy on Cloudflare Pages` | รั่วไหลผู้ให้บริการโฮสติ้ง | *(นำออกจากหน้าจอสาธารณะ)* | ส่วนท้ายเว็บ (Footer) |
| `GitHub Repository` | ศัพท์นักพัฒนา | **ศูนย์ช่วยเหลือและรับฟังข้อเสนอแนะ** | ลิงก์ส่วนท้ายเว็บ |

## 4. หมวดการตรวจความถูกต้องของข้อมูล (Validation & Errors)

| ศัพท์เดิม / ศัพท์เทคนิค | ปัญหาที่พบ | คำแนะนำสำหรับผู้ใช้งานทั่วไป | ตัวอย่างบริบทการใช้งาน |
|---|---|---|---|
| `เลขประจำตัวประชาชนไม่ถูกต้องตามหลัก Modulo 11` | มีศัพท์คณิตศาสตร์ที่ไม่จำเป็น | **เลขบัตรประชาชนไม่ถูกต้อง — กรุณาตรวจตัวเลข 13 หลักอีกครั้ง (ระบบตรวจหลักตรวจสอบให้แล้ว)** | ช่องกรอกเลขบัตรประชาชน |
| `Invalid Email Format / Regex mismatch` | ศัพท์การเขียนโปรแกรม | **รูปแบบอีเมลไม่ถูกต้อง (ตัวอย่างที่ถูกต้อง: name@example.com)** | ช่องกรอกอีเมล |
| `String length exceeds 255 chars` | ผู้ใช้ไม่เข้าใจเลขฐาน 2 | **ข้อความยาวเกินกำหนด (กรอกได้ไม่เกิน 250 ตัวอักษร)** | ช่องกรอกหมายเหตุ |
| `Payload size exceeds limit` | ศัพท์เครือข่าย | **ไฟล์มีขนาดใหญ่เกินไป (ขนาดต้องไม่เกิน 5 MB)** | การอัปโหลดไฟล์รูปภาพ |
| `Required field cannot be null` | ศัพท์ฐานข้อมูล (NULL) | **กรุณากรอกข้อมูลในช่องนี้ (จำเป็นต้องระบุ)** | ข้อความเตือนใต้ช่องกรอก |
| `Type mismatch: expected Integer` | ผู้ใช้ไม่เข้าใจ Data Type | **กรุณากรอกเฉพาะตัวเลขเท่านั้น** | ช่องกรอกจำนวนเงิน / อายุ |
| `Duplicate entry for key PRIMARY` | ข้อความจากฐานข้อมูล MySQL | **ข้อมูลนี้มีอยู่ในระบบแล้ว (เลขบัตร/รหัสซ้ำ)** | ข้อผิดพลาดตอนกดบันทึก |

## 5. หมวดปุ่ม การกระทำ และฟังก์ชัน (Buttons & Actions)

| ศัพท์เดิม | ปัญหาที่พบ | คำแนะนำสำหรับผู้ใช้งานทั่วไป |
|---|---|---|
| `Submit` | แปลตรงตัวว่า "ส่ง" ซึ่งกำกวม | **บันทึกข้อมูล** / **ยืนยันการสมัคร** / **ส่งคำขออนุมัติ** (ระบุให้ชัดว่าทำอะไร) |
| `Reset` / `Clear` | เสี่ยงต่อการเผลอกดล้างข้อมูล | **ล้างข้อมูลที่กรอกทั้งหมด** (พร้อมกล่องข้อความยืนยันก่อนลบ) |
| `Execute` / `Run Batch` | ศัพท์รันสคริปต์คอมพิวเตอร์ | **เริ่มส่งข้อความ** / **เริ่มประมวลผล** |
| `Fetch Data` | ศัพท์การดึง API | **อัปเดตข้อมูลล่าสุด** / **ดึงข้อมูล** |
| `Filter Query` | ศัพท์ฐานข้อมูล | **ค้นหาอย่างละเอียด** / **ตัวกรอง** |
| `Export CSV / Dump` | ศัพท์เทคนิค | **ดาวน์โหลดเป็นไฟล์ Excel (.csv)** |
| `Import Bulk` | ทับศัพท์ | **นำเข้าไฟล์รายชื่อพร้อมกันหลายรายการ** |
| `View Log` | ศัพท์บันทึกเหตุการณ์ระบบ | **ดูประวัติการทำรายการ** |
| `Kill Process` / `Abort` | ภาษาทางเทคนิคที่ดูรุนแรง | **ยกเลิกการทำรายการ** |
