# กรณีศึกษา: พอร์ทัลสมาชิก สหกรณ์ออมทรัพย์โรงพยาบาลแพร่ (PhosCoop)

> **ที่มา:** อ้างอิงจากการตรวจสอบจริงในฐานะ *Thai Institutional Copy & Tone Auditor* บนเว็บไซต์ของสหกรณ์ออมทรัพย์โรงพยาบาลแพร่ จำกัด (`/home/songwut/1prog/phoscoop/index.html`)

## 1. บริบทและปัญหาเริ่มต้น (Initial Audit Findings)

จากการตรวจสอบเว็บไซต์สหกรณ์ ซึ่งมีกลุ่มผู้ใช้งานหลักคือสมาชิกสหกรณ์ แพทย์ พยาบาล บุคลากรทางการแพทย์ และผู้เกษียณอายุ พบปัญหาการรั่วไหลของข้อมูลเทคนิคและภาษาที่ไม่เป็นทางการ 4 ประการใหญ่:

1. **การรั่วไหลของชื่อแพลตฟอร์มคลาวด์และโฮสต์หลังบ้าน (Reconnaissance Leaks):**
   - มีข้อความระบุชัดเจนว่า `Deploy บน Cloudflare Pages: phoscoop.pages.dev`
   - ใต้ฟอร์มลงชื่อเข้าใช้ระบุชื่อเซิร์ฟเวอร์: `เซิร์ฟเวอร์: coophpr.thaiddns.com`
   - ในส่วนหน่วยงานที่เกี่ยวข้อง ปรากฏลิงก์ `GitHub Repository` ปนกับหน่วยงานราชการ
2. **การนำชื่อแบรนด์ระบบหลังบ้านของเวนเดอร์มาแสดงซ้ำซ้อน:**
   - ปรากฏคำว่า `Isocare` (ชื่อโปรแกรมระบบงานเดิม) มากถึง 11 จุดทั่วทั้งเมนูและปุ่มกด ทำให้สมาชิกเกิดความสับสนระหว่างชื่อองค์กรสหกรณ์กับชื่อซอฟต์แวร์
3. **การแสดงตัวชี้วัดความเร็วเครือข่ายที่ไม่จำเป็น (Telemetry Leaks):**
   - แสดงค่าเวลาแฝง (Ping Latency) เช่น `(${data.responseTimeMs}ms)` ในป้ายสถานะระบบ
4. **การใช้คำทับศัพท์และคำกำกับภาษาอังกฤษในวงเล็บฟุ่มเฟือย:**
   - ใช้ข้อความเช่น `เลขสมาชิก (Username)`, `รหัสผ่าน (Password)`, `รีเซ็ตรหัสผ่าน`, และการใส่วงเล็บ `(PDF)` ซ้ำซ้อนกว่า 25 จุด

## 2. ตารางการปรับปรุงข้อความสู่ภาษาสถาบัน (Institutional Copy Transformation)

| จุดที่พบใน UI | ข้อความเดิมที่มีปัญหา | ข้อความภาษาไทยทางการสถาบันที่เสนอแนะ | เหตุผลและความปลอดภัย |
|---|---|---|---|
| **ส่วนท้ายเว็บ (Footer)** | `Deploy บน Cloudflare Pages: phoscoop.pages.dev` | *(ตัดออกทั้งหมด)* | ป้องกันการสแกนหาผู้ให้บริการคลาวด์และโดเมนทดสอบ |
| **ใต้ฟอร์มเข้าสู่ระบบ** | `เซิร์ฟเวอร์: coophpr.thaiddns.com` | *(ตัดออกทั้งหมด)* | ป้องกันการชี้เป้าโฮสต์และพอร์ตภายในที่ใช้ DDNS |
| **แถบนำทางและเมนู** | ระบบสมาชิก Isocare ออนไลน์ | **ระบบบริการสมาชิกออนไลน์ สหกรณ์ออมทรัพย์ รพ.แพร่** | ใช้ชื่อทางการของสถาบันแทนชื่อโปรแกรมเวนเดอร์ |
| **ป้ายสถานะระบบ** | `ออนไลน์ (${data.responseTimeMs}ms)` | **ระบบพร้อมให้บริการ** | ผู้ใช้ต้องการทราบแค่ระบบใช้ได้หรือไม่ ไม่ต้องเห็นตัวเลข ms |
| **หน่วยงานที่เกี่ยวข้อง** | `GitHub Repository` | **ศูนย์รับแจ้งปัญหาและข้อเสนอแนะ** | สมาชิกทั่วไปไม่ควรถูกส่งไปยัง Git Source Code |
| **ช่องกรอกข้อมูล** | `เลขสมาชิกสหกรณ์ (Username)` | **เลขที่สมาชิกสหกรณ์** | ภาษาไทยทางการชัดเจน ไม่ต้องใส่วงเล็บภาษาอังกฤษ |
| **ช่องรหัสผ่าน** | `รหัสผ่าน (Password)` | **รหัสผ่าน** | ตัดวงเล็บที่ไม่จำเป็นออก |
| **ปุ่มดาวน์โหลดเอกสาร** | `ดาวน์โหลดแบบฟอร์มกู้เงิน (PDF) (1.4MB)` | **ดาวน์โหลดแบบคำขอกู้เงิน (1.4 MB)** | คำเรียกทางการพร้อมขนาดไฟล์ ตัด (PDF) ซ้ำซ้อน |
| **การลืมรหัสผ่าน** | `รีเซ็ตรหัสผ่าน (Reset Password)` | **ขอตั้งรหัสผ่านใหม่** | ใช้คำไทยทางการที่เข้าใจง่ายสำหรับสมาชิกอาวุโส |

## 3. สรุปคุณค่าที่ได้รับ

- **ความน่าเชื่อถือระดับสถาบันการเงิน:** การใช้ภาษาไทยทางการช่วยเสริมสร้างความเชื่อมั่นแก่สมาชิกในการทำธุรกรรมทางการเงิน
- **ยกระดับความปลอดภัย (Defense in Depth):** ตัดเส้นทางและข้อมูลสถาปัตยกรรมคลาวด์ ไม่เปิดโอกาสให้ผู้ไม่ประสงค์ดีนำชื่อโฮสต์ไปใช้ประโยชน์
- **เข้าถึงง่ายสำหรับทุกวัย:** สมาชิกทุกกลุ่มอายุเข้าใจป้ายและขั้นตอนการใช้งานได้ทันทีโดยไม่ต้องมีความรู้ด้านคอมพิวเตอร์
