# กติกาข้อความป้องกันความผิดพลาดล่วงหน้า (Poka-Yoke Microcopy Rules)

> **แนวคิดหลัก (Poka-Yoke Concept):**  
> ป้องกันข้อผิดพลาดตั้งแต่ก่อนที่ผู้ใช้จะลงมือกดปุ่ม หากผู้ใช้กรอกผิด หรือกดปุ่มผิด นั่นแปลว่า **ข้อความนำทาง (Guiding Microcopy) ยังไม่ชัดเจนพอ**

---

## 1. ป้ายชื่อและคำแนะนำใต้ช่องกรอก (Labels & Helper Text)

### กฎที่ 1: ห้ามพึ่งพา Placeholder เพียงอย่างเดียว
- **ปัญหา:** Placeholder จางมองยาก และจะหายไปทันทีเมื่อผู้ใช้เริ่มพิมพ์ ทำให้ลืมว่าต้องกรอกอะไร
- **แนวทางปฏิบัติ:**
  - ต้องมี `<label>` ชัดเจนเสมอ
  - ใส่ **Helper Text (ข้อความช่วยเหลือ)** ที่มองเห็นตลอดเวลาอยู่ใต้ช่องกรอก
  - ระบุตัวอย่างจริงที่ถูกต้อง เช่น *"ตัวอย่าง: 081-234-5678"*

```html
<!-- ตัวอย่างที่ดี -->
<div class="field">
  <label for="campaign-name">ชื่อโครงการส่งข้อความ <span class="required">*</span></label>
  <input id="campaign-name" type="text" aria-describedby="campaign-hint" />
  <p id="campaign-hint" class="helper-text">
    ตั้งชื่อที่สื่อถึงกลุ่มเป้าหมาย (ตัวอย่าง: แจ้งนัดตรวจสุขภาพประจำปีกลุ่มผู้สูงอายุ) ความยาวไม่เกิน 50 ตัวอักษร
  </p>
</div>
```

## 2. ปุ่มกดที่บอกผลลัพธ์ล่วงหน้า (Action Buttons with Clear Outcomes)

### กฎที่ 2: บอกผลลัพธ์ที่จะเกิดขึ้น ไม่ใช่แค่บอกการทำงานของระบบ
| ปุ่มเดิม (กำกวม) | ปุ่มใหม่ (ตามแนวทาง Poka-Yoke) | ผลลัพธ์ |
|---|---|---|
| `อนุมัติ` | **อนุมัติและเริ่มส่งข้อความทันที** | ผู้ใช้อนุมัติรู้ว่าจะมีการยิงข้อความออกไปจริง |
| `ส่งต่อ` | **ส่งต่อให้ผู้กำหนดเป้าหมายเลือกรายชื่อ** | รู้ว่าขั้นตอนถัดไปใครจะเป็นคนทำต่อ |
| `ลบ` | **ลบโครงการนี้ (ไม่สามารถกู้คืนได้)** | เตือนผลกระทบขั้นเด็ดขาดล่วงหน้า |
| `ตกลง` | **ยืนยันการบันทึก** | ชัดเจน ไม่สับสนกับปุ่มยกเลิก |

### กฎที่ 3: ปุ่มที่ปิดใช้งาน (Disabled Button) ต้องมีคำอธิบายเสมอ
- หากปุ่มเป็นสีเทาและกดไม่ได้ **ต้องบอกเหตุผลเสมอ** ว่าผู้ใช้ต้องทำอะไรเพิ่มเติมปุ่มถึงจะกดได้
- *ตัวอย่าง:* ใต้ปุ่มสีเทามีข้อความระบุว่า:  
  > ℹ️ *"ปุ่ม 'ส่งคำขอ' จะเปิดให้กดได้ เมื่อท่านแนบไฟล์รายชื่อและตรวจความถูกต้องครบถ้วนแล้ว"*

## 3. หน้าจอว่างเปล่าเชิงสอนงาน (Educational Empty States)

### กฎที่ 4: ห้ามปล่อยหน้าจอว่างเปล่า หรือขึ้นแค่ "ไม่พบข้อมูล"
หน้าจอที่ยังไม่มีข้อมูลคือโอกาสทองในการ **สอนงาน (Onboarding)** ให้ผู้ใช้เข้าใจระบบโดยไม่ต้องเปิดคู่มือ

```
+-----------------------------------------------------------------------------------+
|                            โครงสร้าง Empty State ที่ดี                            |
+-----------------------------------------------------------------------------------+
|                                 [ ไอคอนประกอบ ]                                  |
|                                                                                   |
|                   ยังไม่มีโครงการส่งข้อความในระบบ                                 |
|                                                                                   |
|     เริ่มต้นสร้างโครงการแรกเพื่อส่งข้อความแจ้งเตือนสุขภาพถึงผู้รับบริการ          |
|     ผ่านระบบ LINE Official Account ได้ง่าย ๆ (ใช้เวลาประมาณ 3 นาที)               |
|                                                                                   |
|                           [ + สร้างโครงการแรกของคุณ ]                             |
+-----------------------------------------------------------------------------------+
```

---

## 4. กล่องยืนยันการกระทำสำคัญ (Irreversible Action Confirmation)

### กฎที่ 5: ห้ามใช้ Browser `confirm()` หรือ `alert()` ลอย ๆ
- ห้ามถามแค่ว่า: `"Are you sure?"` หรือ `"คุณแน่ใจหรือไม่?"`
- ให้ระบุรายละเอียดสิ่งที่กำลังจะทำ ปริมาณผลกระทบ และผลลัพธ์ที่ย้อนกลับไม่ได้:

```
+-----------------------------------------------------------------------------------+
|                        ยืนยันการส่งข้อความแจ้งเตือนสุขภาพ                         |
+-----------------------------------------------------------------------------------+
| คุณกำลังจะส่งข้อความถึงผู้รับบริการจำนวน 1,420 ราย                                |
|                                                                                   |
| ข้อความที่จะส่ง: "แจ้งเตือนนัดตรวจสุขภาพคลินิกโรคเบาหวาน วันที่ 15 พ.ย. 69..."    |
|                                                                                   |
| หมายเหตุ: เมื่อยืนยันแล้วระบบจะเริ่มส่งทันทีและไม่สามารถยกเลิกข้อความกลางคันได้   |
|                                                                                   |
|                 [ ยกเลิก / กลับไปแก้ไข ]     [ ยืนยันและเริ่มส่งทันที ]            |
+-----------------------------------------------------------------------------------+
```
